# homebrew-cgraph

Homebrew tap for [CGraph](https://github.com/Nxtsoft/CGraph), a code graph and change-context engine for coding agents.

```sh
brew install nxtsoft/cgraph/cgraph
```

`Formula/cgraph.rb` is generated by `scripts/pin_launcher_release.py` in the CGraph repository from the same release assets as the plugin launcher. Do not edit it here by hand.
